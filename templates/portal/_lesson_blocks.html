READ THIS BEFORE WIDENING WHAT WRITES A LessonBlock. markdownify_inline ends in mark_safe() with no sanitiser, so every prose slot below is an HTML sink. That is safe TODAY only because the seed commands are the sole writer — there is no admin registration, no view and no AI path that can create or edit a block. The moment one of those exists, the prose fields need sanitising; the escaped fields (title, math, answer, table cells) and json_script do not. The order of kinds below mirrors the lesson template the course standardised on: why it exists, then the ideas, then the recipe, then examples, then the mistakes. {% endcomment %}
